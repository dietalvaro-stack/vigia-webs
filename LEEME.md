# Vigía de las webs

Cada 10 minutos GitHub abre dietalvaro.com, membresia.dietalvaro.com y su /login/.
Si alguna no responde bien dos veces seguidas, la vuelta sale en rojo y GitHub manda un correo.

Ver cómo va: https://github.com/dietalvaro-stack/vigia-webs/actions

Para añadir una web, se mete en `URLS` de `.github/workflows/vigia.yml`.
